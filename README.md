# 🧠 사고 깊이 자가진단

당신의 사고 방식이 얼마나 깊고 입체적인지 **10가지 영역 · 40문항**으로 측정하는 자가진단 웹사이트입니다.

---

## 📸 미리보기

| 인트로 | 진단 | 결과 |
|--------|------|------|
| 시작 화면 + 점수 범례 | 카테고리별 문항 + 진행도 | 총점 · 링 차트 · 영역별 막대 |

---

## 🎯 진단 영역 (10개)

| # | 영역 | 설명 |
|---|------|------|
| 1️⃣ | 다중 관점 능력 | 하나의 문제를 여러 이해관계자 시선으로 바라보는 능력 |
| 2️⃣ | 추상화 깊이 | 현상 뒤의 구조와 원리를 파악하는 능력 |
| 3️⃣ | 인과 확장성 | 결정의 2~3단계 후폭풍을 예측하는 능력 |
| 4️⃣ | 시간 지평 | 1년 이상의 장기 관점으로 사고하는 능력 |
| 5️⃣ | 메타인지 | 자신의 사고 방식을 인식하고 분석하는 능력 |
| 6️⃣ | 모순 수용 능력 | 상충하는 두 입장을 동시에 이해하는 능력 |
| 7️⃣ | 구조화 능력 | 복잡한 문제를 레이어와 체계로 정리하는 능력 |
| 8️⃣ | 실행 연결성 | 깊은 고민을 실제 산출물로 전환하는 능력 |
| 9️⃣ | 정체성 통합 | 커리어·재정·가치관을 연결해 사고하는 능력 |
| 🔟 | 사고 유연성 | 새 정보에 따라 기존 판단을 수정하는 능력 |

---

## 📊 점수 기준

각 문항 **0~4점** · 총 **160점 만점**

| 점수 | 라벨 | 의미 |
|------|------|------|
| 0 | 거의 못함 | 해당 역량이 거의 발휘되지 않음 |
| 1 | 가끔 함 | 특정 상황에서 드물게 나타남 |
| 2 | 의식하면 가능 | 의도적으로 신경 쓸 때 가능 |
| 3 | 자연스럽게 함 | 별다른 노력 없이 발휘됨 |
| 4 | 항상 자동적으로 함 | 완전히 내재화된 역량 |

## 🏆 결과 레벨

| 점수 범위 | 레벨 | 특징 |
|-----------|------|------|
| 151 – 160 | 통합형 사고 | 창업가/아키텍트 레벨 · 추상-구조-실행 연결 완성형 |
| 121 – 150 | 전략가형 사고 | 시스템 설계자 레벨 · 구조·시간·인과 확장성 높음 |
| 81 – 120 | 구조적 사고 가능 | PM/기획 상위권 · 다층 분석 가능 |
| 0 – 80 | 실무 중심 사고 | 실행 중심 · 구조적 확장성 성장 여지 큼 |

## 🚀 사용법

별도 설치 없이 브라우저에서 바로 실행됩니다.

```bash
# 저장소 클론
git clone https://github.com/Kimajun0919/Thought-depth-self-diagnosis.git
cd Thought-depth-self-diagnosis

# index.html을 브라우저로 열기
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

또는 `index.html` 파일을 브라우저에 드래그 앤 드롭하면 됩니다.

---

## 🛠 기술 스택

- **HTML5 / CSS3 / Vanilla JS** — 외부 라이브러리 의존성 없음
- **단일 파일** (`index.html`) — 설치·빌드 불필요
- **반응형 디자인** — 모바일·태블릿·데스크톱 모두 지원

---

## ✨ 주요 기능

- **실시간 진행도 바** — 답변할수록 상단 바가 채워짐
- **40문항 모두 완료** 시 결과 보기 버튼 활성화
- **원형 링 차트** — 달성률 애니메이션 표시
- **영역별 막대 그래프** — 10개 카테고리 점수 시각화
- **강점/성장 영역** 자동 분석
- **다시 진단하기** 버튼으로 재시도 가능
